# To Do List Web App

A simple and interactive To Do List web application built using HTML, CSS, and JavaScript. The application allows users to manage daily tasks by adding, editing, deleting, and storing tasks using the browser's Local Storage.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Store tasks using Local Storage
- Automatically load saved tasks after page refresh
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and layout
- `script.js` – Task management and Local Storage logic

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using the Live Server extension or any web browser.

## How It Works

1. Enter a task in the input field.
2. Click the **Add** button to save the task.
3. Edit or delete tasks anytime.
4. All tasks are automatically saved in the browser's Local Storage.
5. Saved tasks remain available even after refreshing the page.
